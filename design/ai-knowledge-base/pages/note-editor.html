React 18 并发特性详解

React 18 的核心是并发渲染。它让界面在处理大量更新时依然保持流畅响应。本篇笔记梳理最值得关注的能力，并给出实际的升级建议。

并发渲染

并发渲染让 React 能够中断、暂停并恢复渲染过程。要启用它，需要将根节点挂载方式替换为 createRoot。 

import { createRoot } from 'react-dom/client';

const root = createRoot(document.getElementById('root'));
root.render(<App />);

useTransition

useTransition 用于标记非紧急的状态更新，让紧急更新（如输入框打字）优先响应，从而避免界面卡顿。

useDeferredValue

与之互补的 useDeferredValue 可以延迟派生值的更新，适合在搜索、筛选场景中让渲染压力大的列表滞后于输入框重绘。

自动批处理

在 React 18 中，多次状态更新会被自动合并为一次重渲染，覆盖范围扩展到 Promise、setTimeout 与原生事件回调中，主要收益包括：

  • 异步回调中的多次 setState 也会合并，无需手动包裹。
  • 渲染次数下降，交互响应更平滑。
  • 如需退出批处理，可使用 flushSync 立即刷新。

Suspense 流式渲染

React 18 为服务端渲染带来了流式 HTML 与选择性水合。页面可分块传输，用户能更早看到内容，显著提升首屏体验。

流式渲染让首屏时间与可交互时间解耦，体验的提升是渐进而非全有全无的。

升级建议

对大多数应用而言，切换到 createRoot 即可获得自动批处理收益。并发特性建议按需引入，优先在明显卡顿的大列表场景验证效果。
