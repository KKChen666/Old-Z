## 新增功能：笔记内 @文件 + 点击预览（含 HTML）

### 需求
用户希望在笔记中 @ 文件，艾特后可在笔记里点击预览；文件需支持 HTML，且 HTML 也能预览。

### 实现要点
**前端（src/pages/Notes.tsx + src/components/FilePreview/）**
1. 新增 `HtmlViewer.tsx`：用 `sandbox="allow-scripts"`（不含 allow-same-origin）的 `<iframe srcDoc>` 安全渲染用户上传的 HTML，避免 XSS 逃逸到主应用。
2. `FilePreview/index.tsx`：把 html/htm 从 text 类别拆出，新增 `html` 类别 → 懒加载 `HtmlViewer`。
3. 笔记 @文件：
   - 自定义 scheme `oldzfile://<fileId>`，插入 token `[@文件名](oldzfile://<id>)` 到 MDXEditor 光标处（insertMarkdown）。
   - 编辑器工具栏新增「链接文件」按钮（Paperclip 图标）打开文件选择器弹窗。
   - 输入 `@`（行首或空白后、非 IME 组合、非邮箱场景）自动弹出文件选择器；keydown 阶段 `preventDefault` 拦截 @ 写入，避免游离字符。
   - 阅读视图用 ReactMarkdown 自定义 `a` 组件：命中 `oldzfile://` 渲染为可点击芯片，点击打开 `FilePreview`；`urlTransform` 放行该 scheme、拦截 javascript/data/vbscript。
   - 编辑视图 `handleEditorClick` 拦截 `oldzfile://` 锚点点击 → 打开 `FilePreview`。
4. 文件选择器弹窗支持搜索（mentionSearch + mentionFiles 过滤 memo），Enter 选中首个。

**后端（api/routes/notes.ts）**
- PATCH /:id：解析正文 `oldzfile://<id>`，校验归属（files 表 user_id），`DELETE + INSERT IGNORE` 同步 `note_files` 关联表，持久化 linkedFileIds。GET / 已把 note_files 映射为 linkedFileIds 返回。

### 验证
- `npx tsc --noEmit` 零错误 ✓
- `npx vite build` 成功 ✓（Notes chunk 109KB，HtmlViewer 按需懒加载）
